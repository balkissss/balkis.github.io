# Balkis Selmi — Portfolio

A modern, responsive personal portfolio website built for GitHub Pages.

## 🚀 Live Site
This repository is configured to publish automatically via **GitHub Pages** at:
`https://balkis.github.io/`

## ✨ Features
- **Hero** with animated background, profile photo and key highlights
- **About** — summary, location, languages and personal motto
- **Skills** — Remote Sensing/GIS, Programming, AI/ML, Web & Mobile, Image Processing
- **Experience** — interactive timeline of internships & civic roles
- **Education** — Geomatics engineering at Manouba School of Engineering
- **Projects** — HydroTwin, Drought Dashboard, Petrel coordinate conversion & more
- **Achievements** — awards, conferences and recognitions
- **Certificates** — filterable gallery with lightbox
- **Gallery** — photo gallery from events and life
- **Contact** — email, phone, GitHub, LinkedIn + downloadable CV

## 🛠️ Tech
- HTML5, CSS3 (custom design system, responsive), Vanilla JavaScript
- Google Fonts (Sora + Inter), Font Awesome icons
- IntersectionObserver reveal animations, filter & lightbox (no frameworks)

## 🧭 How to use
1. Push the contents of this folder to the `main` branch of `balkis.github.io`.
2. In the repository **Settings → Pages**, set source to `Deploy from a branch` → `main` / `/ (root)`.
3. Your site is live at `https://balkis.github.io/`.

> Tip: Update the GitHub / LinkedIn URLs in `index.html` with your real profile links.
